# Sprints

Each sprint ends with a 5–10 slide [Marp](https://marp.app) deck (`sprint-N/deck.md`), presented out loud and recorded. The critique it received, and my rebuttal, go in `sprint-N/review.md`.

Render with `npx @marp-team/marp-cli sprints/sprint-1/deck.md --pdf`.

Each deck should cover: what I set out to do, what I tried, what failed and why, what I now believe, and what's next. Use figures, tables and diagrams, not walls of text.
